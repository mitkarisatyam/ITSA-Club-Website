# ITSA — Information Technology Students Association, VIT Pune

A high-performance, immersive website for **ITSA — Information Technology Students Association, VIT Pune**. Features interactive 3D WebGL scenes, particle physics, custom typography, GSAP animations, responsive layouts, and domain project showcases.

## 🏛️ Sections Overview

1. **Hero Section**: 
   - Headline: *Ideas Into Code. Code Into Impact.*
   - Supporting text: *ITSA — the Information Technology Students Association at VIT Pune — brings students together to explore technology, develop skills, collaborate on ideas, and create meaningful projects.*
   - CTAs: *EXPLORE ITSA* & *DISCOVER OUR WORK*
   - Interactive 3D particle star geometry.
2. **About ITSA**: 
   - *More Than Just Technology.*
   - Mission statement, collaborative learning culture, and curiosity-driven innovation.
3. **Projects & Innovation**: 
   - *From Ideas to Implementation.*
   - Practical solution showcases with 3D canvas interaction.
4. **Technical Division**: 
   - *Where Technology Meets Creativity.*
   - Web Development, Artificial Intelligence & Machine Learning (AIML), Data Structures & Algorithms (DSA).
5. **Community & Activities**: 
   - *Learn Together. Build Together.*
   - *Built by People Who Care.*
6. **Recruitment**: 
   - *Find Your Place at ITSA.*
   - Confirmed 5 Divisions & 12 Positions:
     - **Branding Division**: Graphics Head, Media Head
     - **Operations Division**: Operations Head, Database Head, Aesthetics Head
     - **Relations Division**: Industry Relations Head, Sponsorship Head, Publicity Head
     - **Technical Division**: Web Development Head, AIML Head, DSA Head
     - **Finance Division**: Finance Head
   - Eligibility: *Applicants must demonstrate leadership, responsibility, and a strong interest in contributing to ITSA.*
7. **Final Call to Action**: 
   - *Ready to Be Part of ITSA?*
   - Button: *JOIN ITSA*

## 🏃 Running the Server

To restart the server at any time, run:

```powershell
node server.js
```
or:
```powershell
npm start
```
